# Contributing to PlantCellTwin

Report problems or request support through
https://github.com/lissandrakruse/PlantCellTwin/issues. Include the operating
system, Python or R version, command, error message, and dataset accession.

For code contributions:

1. Fork the repository and create a focused branch.
2. Install `environment.yml`.
3. Keep observed, derived, predicted, and hypothetical values labeled.
4. Add or update a test when behavior changes.
5. Run `./run_verification.sh`.
6. Open a pull request describing the scientific and software impact.

Contributions are accepted under the MIT License.
